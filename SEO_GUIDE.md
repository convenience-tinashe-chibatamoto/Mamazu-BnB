## 🌐 When You Get a Custom Domain

If you switch from Hostinger subdomain to a custom domain (e.g., mamazubnb.com):

1. Update all URLs in:
   - `index.html` (canonical, OG tags, structured data)
   - `sitemap.xml`
   - `robots.txt`

2. Set up 301 redirects from old domain to new domain

3. Re-submit sitemap to Google Search Console

4. Update Google My Business with new URL
